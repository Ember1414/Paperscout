# PaperScout v3 验收手册

> 配套文档：`docs/REBUILD_PLAN.md`（施工依据）
> 使用者：项目 owner（唯一验收者）
> 原则：**只信可复现的证据；优先做交互，不只看截图。**

## 0. 验收怎么用（3 分钟版）

1. 打开该里程碑的 preview URL（agent 必须提供，格式 `https://<hash>.paperscout.pages.dev`）。
2. 只勾选本里程碑对应的组（见文末"M 表"）。
3. 每条用例：按"步骤"操作 → 对照"预期" → 勾 ✅ / ❌。
4. 任一带 `[必]` 的用例 ❌ → 该里程碑不通过，填第 6 节缺陷单退回。
5. 通过后：在文末签名行写日期与版本，agent 才能进入下一里程碑。

**判定约定**

| 标记 | 含义 |
|------|------|
| `[必]` | 不通过则里程碑不通过 |
| `[可]` | 记录问题但不阻塞上线 |
| `[机]` | 由 `npm run verify` 自动判定，人工只核对输出 |
| `[人]` | 必须人工操作判定（脚本无法覆盖） |

**三条铁律**
- 视觉正常但点击无反应 → **P0**，不看其他项直接退回。
- 同一操作连续两次结果不一致 → **P0**（不确定本身就是缺陷）。
- "看起来能用"不算通过，必须能把预期逐字对上。
