# M1-06 BM25 + rank + explain

## 变更

- 新增 `functions/lib/query/stopwords.ts`（中英双语停用词 ~120 词）
- 新增 `functions/lib/query/parse.ts`：`parseQuery()`（短语/排除词/字段标签/裸 DOI 意图/中文 2-gram+整串/question 意图/语言判定）、`extractDoi()`、`cjkBigrams()`
- 新增 `functions/lib/core/bm25.ts`：池内 BM25（k1=1.2, b=0.75，IDF 池内计算），字段权重 title×2.2/abstract×1.0/venue×0.3，引号短语 +1.5，标题完全匹配置顶 +5，中文整串命中 +0.5（附录 B 的 ×2 语义落在整串与 bigram 双通道）
- 新增 `functions/lib/core/venues.ts`：顶刊顶会白名单首版 ~40 条（M3-09 扩至 120 条+缩写展开）
- 新增 `functions/lib/core/rank.ts`：五分项（relevance/quality/recency/availability/agreement）+ 加权和 total；sort=newest/cited 只按该键
- 新增 `functions/lib/core/explain.ts`：chip 由分项真实推导，**按贡献度（分项权重）取前三**，文案含真实数字（如 高被引 1.5k）
- 新增 `tests/unit/rank.test.ts`（15 例）
