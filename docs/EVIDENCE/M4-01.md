# M4-01 /api/author 同名消歧 + 作者/机构/期刊服务

## 变更
- 新增 `functions/lib/services/author.ts`：
  - `searchAuthors(name)` 同名消歧候选 ≤5（按 works_count 降序，含机构/orcid）——F-70 不自动跳第一个
  - `getAuthorDetail(id)` 身份卡（h-index/i10/机构/年份范围/主题分布/产出时间线/被引趋势）+ Top10 作品 + 合作者 Top10（从 50 篇作品提取）
- 新增 `functions/lib/services/org.ts` `getOrgDetail(id)`（产出/被引/h-index/主题/趋势）
- 新增 `functions/lib/services/venue.ts` `getVenueDetail(id)`（ISSN/出版社/年发文/被引/Top 5 高被引/主题）
- 路由 `/api/author?id=`（详情）或 `?name=`（消歧候选）；`/api/org?id=`；`/api/venue?id=`
- 移除 v2 legacy `case 'author': return authorProfile(env, url)`（M4 新实现接管）
