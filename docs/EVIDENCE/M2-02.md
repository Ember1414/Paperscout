# M2-02 AppShell + Router + SPA 回退 + 404

## 变更

- 新增 `public/js/router.js`：History API 路由——路径模式匹配（`/p/:id`）、动态 `import()` 按视图分包（7.2）、滚动记忆（`history.scrollRestoration='manual'` + popstate 恢复 + 新页回顶，I-05）、站内 `<a data-link>` 事件委托拦截（⌘/Ctrl+点击不拦截，新标签可用）、视图卸载 `destroy()` 清理
- 新增 `public/js/ui/shell.js`：AppShell（logo/文库/关于/主题按钮 + `<main id=main aria-live=polite>` + 常驻免责页脚）
- 新增 `public/js/views/notfound.js`（404：说明 + 回首页 + 旧版入口）、`views/home.js`（可用的检索入口 → `/search?q=`，M2-04 完整化）、`views/search.js` / `views/advanced.js`（M2-05/07 占位）
- `public/js/app.js`：壳层挂载 + 路由启动接线
- 新增 `public/_redirects`（`/* /index.html 200`）与 `public/_routes.json`（Functions 仅处理 `/api/*`，静态请求零 Functions 开销）
