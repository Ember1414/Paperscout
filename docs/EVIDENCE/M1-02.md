二轮复测（见对话记录/结论）：
- arXiv 本机两轮不可达 → **经 CF 出口实测**：`curl 生产 /api/search?sources=arxiv` → 5 篇、无错误 → verified
- DBLP：202×2（本机）+ CF 出口 HTML 封锁页（"Oh noes!"，Anubis 反爬）+ 30s 冷却后仍 202 → **持久封锁，external-link**
- SciELO：搜索 403 + OAI 404；J-STAGE：两轮连接超时；ChinaXiv：OAI DNS 失效、主站 200 但无结构化检索 API
- Semantic Scholar：429×2（瞬时限流，结构正常）→ 保留 verified，降级兜底

`npx tsc --noEmit` → 0 error（registry 状态更新后）。
