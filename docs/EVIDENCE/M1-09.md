# M1-09 缓存分层 L0/L1/L2 + canonical hash + X-Cache

## 变更

- `functions/lib/infra/cache.ts` 扩齐三层（7.6）：
  - L0 isolate 内存（60s，≤50 项近似 LRU）
  - L1 Cache API（`caches.default`，key=`https://cache.internal/search/<hash>`，600s；**写入由调用方挂 ctx.waitUntil**——A-07 修复）
  - L2 KV `pool:<hash>`（**在线只读**，仅 Warmer 预热写入——铁律"热路径 KV 不写"；本任务在线写路径 0 次 KV 写）
  - `canonicalHash`：源排序/去默认值/trim/小写；**page/limit 不进 hash**（A-08 根治）
- `functions/lib/core/pool.ts`：SearchPool 增加 `exhausted` 标记（缓存命中后翻页判定不再重复召回）
- `functions/lib/services/search.ts`：读 L0→L1→L2（命中即跳过 fan-out 直接切片）；写 L0 + L1（waitUntil）
- `functions/api/[[route]].ts`：v3 响应头 `X-Cache: l0|l1|l2|miss` + `X-Request-Id`；env/ctx 注入编排器
- 新增 `tests/unit/cache.test.ts`（8 例）
