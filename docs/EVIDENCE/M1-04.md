# M1-04 normalize 归一化纯函数

## 变更

- 新增 `functions/lib/core/normalize.ts`：`normalizeDoi`（前缀剥离/小写/尾标点/`10.`+2 位注册码校验）、`titleFingerprint`（NFKC+实体+标点剥离）、`titleMainPart`（去副标题）、`normalizeAuthorName`/`authorKey`/`authorSurname`、`parseYear`（1800..当年+1）、`normalizeVenue`/`venueKey`（Proceedings of (the) 完整前缀剥离）、`cleanAbstract`（JATS 清洗 + 3000 字上限）、`detectLang`（A-05 对称修复）、`dice2`（k3 阈值用 2-gram Dice）
- 新增 `tests/unit/normalize.test.ts`（**31 例**，满足 DoD ≥20 例）

## 证据

- `npm run test` → **7 文件 93 例全 passed**（新增 31 例）
- DoD 用例：`normalizeDoi('10.1000/ABC.')` → `'10.1000/abc'` ✓
- 关键断言：
  - 反例组：`not-a-doi`/`11.1000/abc`/非 DOI URL → undefined；`parseYear(1799)`/当年+2 → undefined；纯标签摘要 → undefined
  - A-05 对称性：`detectLang('English Title','中文摘要')` → zh（v2 只看标题会判错）；`detectLang('English Title','English abstract')` → en
  - `titleFingerprint('ＧＮＮｓ')` → `'gnns'`（NFKC 全角折叠）
  - `normalizeVenue('Proceedings of the 35th NeurIPS')` → `'35th NeurIPS'`；`'Proceedings Journal'` 不被误剥
  - `dice2` 相同串=1、无关串<0.3（k3 阈值 0.92 的两侧）
- `npx tsc --noEmit` → 0 error；`npm run verify` → ALL GREEN
