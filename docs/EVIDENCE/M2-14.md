## 变更

- **中英互译查询扩展**（补功能全景 P0"中英关键词互译扩展"）：
  - 新增 `functions/lib/query/dict.ts`：76 对高置信学术词双语词典（整串+单词级双向索引；宁缺毋滥原则）
  - `expandQuery()`：zh→en 召回后缀（仅 openalex/crossref——自然语言匹配语义源）+ 打分扩展词（并入 BM25 词项，池内 IDF 自适应降权）
  - `FetchRawOpts.querySuffix` 贯通 types→openalex/crossref→编排器
- **DSL 字段意图落地**（评测暴露的实缺）：`author:`/`year:` 标签 → 源级过滤（author 传各源 author 参数；year:2020-2024 拆 from/to）；`ParsedQuery.cleanQuery`（剥离标签后的自由文本供源检索，避免把 DSL 当全文）
- **OpenAlex 作者名回退**：handle/连写名（author:yoshuabengio）在 raw_author_name.search 零命中时降级纯文本检索一次（实测 handle 在 OpenAlex 作者过滤为 0、自由文本命中 70470 条且首位即 Bengio 论文）
- **缓存键补洞**：author 纳入 canonicalHash（否则 author: 查询会串池）
- **检查机制升级**：新增 `scripts/eval-relevance.mjs` + `npm run eval`——金标准 12 查询自动量化（结果数/源OK/Top10 覆盖率/跑题占比/双口径重复率/耗时），zh 查询按中英词合集口径、DOI/全停用词/sort≠smart 正确豁免，输出 JSON 报告
- 新增 `tests/unit/expand.test.ts` 7 例
