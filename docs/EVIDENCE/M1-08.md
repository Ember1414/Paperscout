# M1-08 检索编排器 + 路由 feature flag

## 变更

- 新增 `functions/lib/services/search.ts`：`runSearch()` 编排主流程——parseQuery → 源选择（DOI 意图直查 OpenAlex→Crossref；lang=zh 强制含 openalex/crossref；type=preprint 移除 pubmed/doaj；`truncateByTier` 9 源上限）→ Semaphore(6) 并发 fan-out（软超时由 fetchUpstream 4.5s + 全局 6.5s 硬截止 race，超时源标 timeout、已得结果照常返回）→ fuseRecords → applyFilters（排除词/语言/类型严格过滤=A-04）→ rankWorks → 结果池（不足且上游有货时追加召回 ≤3 轮，全池重排）→ slicePage；L0 缓存 60s（M1-09 扩 L1/L2）
- 新增 `functions/lib/infra/semaphore.ts`、`functions/lib/infra/cache.ts`（canonicalHash + L0 ≤50 项；**hash 不含 page/limit**——A-08 根治）
- `functions/api/[[route]].ts`：`env.SEARCH_V3 === '1'` 时 `/api/search` 走 v3（8.5 feature flag 迁移）；v3 响应 = 7.5 信封 `{ok,data,meta}`，`data.items` 与 `data.papers` 双字段（R-08 兼容），错误走 AppError→errorEnvelope（不回显上游 detail），requestId 贯穿日志
- `functions/lib/types.ts`：Env 增加 `SEARCH_V3?: string`
- 新增 `tests/unit/orchestrator.test.ts`（9 例）
